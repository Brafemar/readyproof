# Instalación de readyproof

Pendiente de la etapa 9.

La [guía de instalación y operación en DigitalOcean](DEPLOYMENT_DIGITALOCEAN.md) contiene la propuesta de configuración, bootstrap privado, HTTPS, respaldo y monitoreo. Para el entorno local, consultar la [guía de acceso](GUIA_ACCESO_BRAFEMAR.md) y el [checklist de entrega](CHECKLIST_ENTREGA_BRAFEMAR.md).
